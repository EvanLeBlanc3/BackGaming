# BackGaming 🎮
Your video game backlog. Log games you want to play, start runs, clear them, earn XP.

## Install on iPhone (GitHub Pages, same as before)
1. Create a new GitHub repo (e.g. `backgaming`) and upload everything in this folder: `index.html`, `app.js`, `sw.js`, `manifest.json`, and the `icons` folder.
2. Repo **Settings → Pages →** Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save.
3. Open the Pages URL in **Safari** on your iPhone → **Share → Add to Home Screen**.
4. Launch it from the Home Screen icon once while online. After that it works offline.

## Backups (Memory Card)
- **PLAYER tab → Export Save File** → choose *Save to Files* (iCloud Drive is safest).
- To restore: **Load Save File** → pick the `.json`. You can choose to merge it with your current games or replace them.
- Alternative: **Copy Backup Code** → paste it into Notes. Restore with **Paste Backup Code**.
- A red dot on PLAYER means you have changes that haven't been backed up in 7+ days.

## XP
Add a game +10 · Start it +25 · Clear it +100 · 250 XP per level.

## Updating
Upload the new files to the repo, then fully close and reopen the app twice so it picks up the new version.
